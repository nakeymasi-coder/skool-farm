How this farm works

This dashboard holds my Skool Intake Form, a Character Vault for my locked characters, solo forms for each of my 5 agents, and a Queue for my runs. Its job is to produce Skool community packages for my community The Glam Vault (https://www.skool.com/the-glam-vault-9512). After I submit a run, my AI runs the farm WITH me in chat and brings the finished community package back for my approval.

Plain honesty: this dashboard is a control panel only (intake, vault, queue). It does not browse, generate images, make videos, access Skool, or post by itself. The work happens in chat from the Run in Chat prompts. Nothing is ever posted automatically. Posting to Skool always needs my separate approval.

The 5 agents, in order

  • Agent 1 - Pinterest Scout: searches Pinterest (guest view, no sign-in) for outfits and products for the chosen mode and topic, especially products with an Amazon link, and for the visuals and topics my Skool members are saving right now. Picks the outfit or product and copies its picture. Does not check price or availability at this step.
  • Agent 2 - Image Agent: creates the person and avatar images in chat - character references, the outfit photo (my locked character wearing the exact Pinterest outfit), and the outfit reference sheet. All ultra realistic, real skin and hair texture, all PNG, all 9:16.
  • Agent 3 - Story Agent: writes the hook, the shots, and the script for video posts and video lessons, and the story arc for text posts. Labels every scene with the run's one Product Presentation choice. Writes scene ACTION only for video prompts - never a description of the character.
  • Agent 4 - Video Agent: makes the video in chat with my AI video tool, using the Consistent Character workflow below. Returns the finished video in chat for my approval. Never posts it.
  • Agent 5 - Skool Copy Agent: writes the Skool copy package - the post title, the full post body in my voice (personable, human, plain words, heart first, saying who it is for and what to do with it), the category pick, one clear call to action, and for a lesson package a short lesson outline (lesson title, what members learn, and the steps in order). No price, discount, or sale claim unless a live price was actually verified - and no buy talk at all when the copy is for inside The Glam Vault.

The 7 modes

  • 1. Announcement / New Drop - a new lesson, resource, or farm is live in the Vault. Category: ANNOUNCEMENTS.
  • 2. Prompt Post - a prompt members can copy, run, and share results from. Category: PROMPTS.
  • 3. Freebie / Resource Drop - a free resource for members. Category: FREEBIES (or a Live Resources lesson package).
  • 4. Lesson / Tutorial - a teach-it step by step Classroom package under Live Resources, often with a video.
  • 5. Engagement / Conversation Starter - a question or share thread that gets members talking in THE HANGOUT.
  • 6. Encouragement / Celebration - kind words in Words Of Encouragement, or a wins thread in Celebrate Your Accomplishments.
  • 7. Product Spotlight - a product or resource shown off for members (Ready To Sell Products inside the Vault with no buy talk; selling copy with a shop link is for outside the Vault only).

The Product Presentation rule

Every run saves ONE Product Presentation choice, right after Mode: None, Wearing the product, Holding the product, Using the product, Showing it close to camera, Sitting beside her in frame, Unboxing / opening it, Holding it up by her face, or Holding in some scenes and wearing in others. Wearing and holding never mix in the same shot. Never show her wearing an outfit while holding that same outfit on a hanger. Reject and regenerate any image that shows both. If a video needs both, use separate scenes - holding first, wearing later - never the same shot. A None run adds no presentation sentence at all.

The Skool standing order

A Skool post is not done until it has a category, one clear call to action, and - when it points somewhere - a working destination link. Inside The Glam Vault there is no buy talk.

Classroom note: my Classroom home for curriculum is Live Resources (a Classroom course, not a feed category). Lesson packages go there - pick "Classroom - Live Resources" instead of a feed category.

The workflow

  1. Pick the outfit on Pinterest (one with an Amazon link when there is a product). Copy its picture. Scout member-loved visuals and topics the same way, in guest view.
  2. Lock the outfit IN CHAT, not in the video tool: using my locked character's reference photos, put that character in that exact outfit in chat first. Check face match and outfit match.
  3. Make the outfit reference sheet IN CHAT: from the approved outfit photo, one single 9:16 sheet with front, profile, and three-quarter shots of her in that outfit, all on the same photo. Save as PNG.
  4. Build the video (when the run has one) with the Consistent Character lock: Reference One is her headshot (Slot 1). Reference Two is the chat-made outfit reference sheet. NEVER leave Reference Two empty. No character bible is needed - the reference photos ARE the lock. Do not paste descriptions of her into scene prompts.
  5. Create the scenes from that lock, in script order, 9:16.
  6. The Skool Copy Agent finishes the package: post title, full post body, category pick, one clear call to action, and a lesson outline when the run is a lesson package.
  7. Return the finished Skool package IN CHAT for my approval. Never post, publish, or share it.

The scene prompt shape

Use this for every scene, and nothing else about her: "Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it." The last sentence swaps to match the run's Product Presentation choice, and a None run adds no presentation sentence at all. NEVER describe her in a scene prompt - no face, hair, skin, body, or outfit description. Describing her overrides the references and creates a different girl.

How Run in Chat works

Every Queue card gets a Run in Chat button. Pressing it sets that run to "working" and opens a Run in Chat card showing the locked character, Slot 1 and Slot 2 status with thumbnails, voice, mode, Product Presentation choice and its exact prompt sentence, topic, length / format, product, reference video link, notes, Skool category, and destination link. The card has a COPY PROMPT button. The copied prompt tells the AI to run THAT exact run with THOSE exact details, nothing swapped, and to bring the finished Skool package back in chat for my approval, never posting it. There is no scheduled pickup.

Queue status buttons only change the label - queued, working, or done. Changing a status does not browse, generate, access Skool, or post anything. Execution happens in chat.

Character Vault - locked characters

One record per locked character. Slot 1 is the headshot, one photo, 9:16. Slot 2 is the body reference sheet: ONE single 9:16 photo - not separate photos - with front, three-quarter, left profile, and right side views of the same person, same outfit, same background, all on that one photo. A character is NOT locked until BOTH slots are filled. Uploads: any image your browser can open (JPG, PNG, or a WebP your browser reads). The farm reads the file directly, shrinks a copy in the browser to a storage-sized JPG (max 1080px) when that works, and if the shrink step fails it keeps the photo exactly as read. A readable photo is never rejected. AI-created images are still PNG only. Characters are ultra realistic, with real skin texture and real hair texture. Every character is African American unless a specific existing character was named. Plus-size stays plus-size, never slimmed down. Within one video, identity, clothing, location, and lighting stay frozen from the reference photos.
