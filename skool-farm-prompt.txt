SKOOL FARM - THE ADAPTED BUILD PROMPT (Glam's Skool edition of the UGC Agent Farm)
Built from THE AGENT FARM BUILD PROMPT (the master farm prompt by Glam, Glam Hustle Hub),
adapted for Skool the same way the Facebook, Instagram, and Pinterest farms were adapted.
Keep the bones. Change only what Skool genuinely changes.
================================================================================
Use this prompt to build / rebuild the dashboard. Where it conflicts with any
default, THIS prompt wins.

THE DASHBOARD
Build a working SKOOL FARM dashboard - a real tool I can use, not a
document, not a lesson, not an explanation of one. Build it as ONE
self-contained interactive page (HTML) that runs when opened. If you cannot
make a file, output the complete code for that page so I can save and open it.
Do NOT stop at a plan or an outline - build the finished, working dashboard.
The farm ships with its own name, icon set, and install manifest from day
one: name "Skool Farm - Glam Hustle Hub", short name "Skool Farm",
manifest.webmanifest, icon-512.png, icon-192.png, apple-touch-icon.png,
and favicon.png in the same folder.

WHAT THIS FARM IS
One dashboard holds my Skool Intake Form, a Character Vault for my locked
characters, solo forms for each of my 5 agents, and a Queue for my runs.
The farm's job is to produce SKOOL COMMUNITY PACKAGES for my community
The Glam Vault (https://www.skool.com/the-glam-vault-9512): community posts,
announcements, prompt posts, freebies, encouragement, celebrations, and
Classroom lesson packages under Live Resources. After I submit a run, my AI
runs the farm WITH me in chat - Pinterest scout, locked character, story,
image or video, Skool copy - and brings the finished community package back
for my approval. NOTHING is ever posted automatically. Say that plainly
inside the dashboard: the dashboard itself is my control panel (intake,
vault, queue); it does not browse, generate images, make videos, access
Skool, or post by itself - the work happens in chat from the Run in Chat
prompts. Posting to Skool always needs my separate approval.

DESIGN
Clean, pretty, phone-first. Light sapphire blue, chrome silver, and pearl
white, soft ombre gradients, with small butterfly touches. Big readable
text, big tap-friendly buttons. Everything that relates to video or
character references is 9:16 vertical. START EMPTY: no test characters,
no test runs, no sample rows anywhere. I add my real characters and runs
myself. The dashboard saves in the browser with localStorage key
skoolFarmV1.

PAGES THE DASHBOARD MUST HAVE
HOME: explains the farm, the 5 agents, the 7 modes, the Product
Presentation rule, the Skool standing order, my real Skool categories,
the Classroom note, Work Hours, and how Run in Chat works.
SKOOL INTAKE FORM: the full farm run form (fields below, in order).
CHARACTER VAULT: locked characters (Character A, B, C...), each reusable
as that same character.
SOLO AGENT FORMS: one form per agent, so I can run a single agent job by
itself.
QUEUE: every full run and solo job in one list, newest first, with a
manual status I can set: queued, working, or done. The status button only
changes the label - it never executes anything. Execution happens in chat.
RUN IN CHAT: the card a Queue run opens into (see RUN IN CHAT below).

SKOOL INTAKE FORM - fields in this exact order:
1. Locked character picker (or "create a new character")
2. Mode (the 7 modes below)
3. PRODUCT PRESENTATION - right after Mode, one single choice: None
   (product not presented, no presentation sentence), Wearing the product,
   Holding the product, Using the product, Showing it close to camera,
   Sitting beside her in frame, Unboxing / opening it, Holding it up by
   her face, or Holding in some scenes and wearing in others. Wearing and
   holding never mix in the same shot. Every form category also offers a
   None option.
4. Topic
5. Length / format (for example: post only, a 30 second video post, or a
   full Classroom lesson package)
6. Product name and product link, when there is one
7. Reference video link, when there is one
8. Notes
9. Skool category - one single choice from my real categories above, or
   None. Classroom lesson packages pick "Classroom - Live Resources"
   instead of a feed category.
10. Destination link, when there is one (a Classroom lesson page, a
    community post, or - for outside-the-Vault copy only - a shop page)
Save that one Product Presentation choice on the run. Show it on the Queue
card and on the Run in Chat card, with its exact prompt sentence (from THE
SCENE PROMPT SHAPE below). Show the Skool category and the destination
link on the Queue card and the Run in Chat card too, and bake them into
the copied prompt.

CHARACTER VAULT - one record per locked character:
- Character letter and name (for example "Character A - Rosa"), plus a
  voice description.
- SLOT 1 - HEADSHOT: one photo, 9:16.
- SLOT 2 - BODY REFERENCE SHEET: ONE single 9:16 photo - not separate
  photos - with front, three-quarter, left profile, and right side views
  of the same person, same outfit, same background, all on that one photo.
- A character is NOT locked until BOTH slots are filled. Say so on the card.
- I can upload a character I already have: headshot for Slot 1, single
  9:16 body reference sheet for Slot 2. My uploads are accepted as any
  image my browser can open (JPG, PNG, or a WebP my browser reads): read
  the file directly, shrink a copy in the browser to a storage-sized JPG
  (max 1080px) when that works, and if the shrink step fails keep the
  photo exactly as read. A readable photo is never rejected. AI-created
  images are still PNG only.
- My characters are ultra realistic, with real skin texture and real hair
  texture. Every character is African American unless I named a specific
  existing character. Plus-size stays plus-size, never slimmed down.
- Within one video, identity, clothing, location, and lighting stay
  frozen from the reference photos.

THE 5 AGENTS - in this order:
AGENT 1 - PINTEREST SCOUT: searches Pinterest (guest view, no sign-in) for
outfits and products for the chosen mode and topic, especially products
with an Amazon link, and for the visuals and topics my Skool members are
saving right now. Picks the outfit/product and copies its picture. Does
not check price or availability at this step.
AGENT 2 - IMAGE AGENT: creates the person and avatar images in chat -
character references, the outfit photo (my locked character wearing the
exact Pinterest outfit), and the outfit reference sheet. All ultra
realistic, real skin and hair texture, all PNG, all 9:16.
AGENT 3 - STORY AGENT: writes the hook, the shots, and the script for
video posts and video lessons, and the story arc for text posts. Labels
every scene with the run's one Product Presentation choice. Writes scene
ACTION only for video prompts - never a description of the character.
AGENT 4 - VIDEO AGENT: makes the video in chat with my AI video tool,
using the Consistent Character workflow below. Returns the finished video
in chat for my approval. Never posts it.
AGENT 5 - SKOOL COPY AGENT: writes the Skool copy package. The POST TITLE,
clear and warm so members know what it is. The full POST BODY in my voice:
personable, human, plain words, heart first, saying who it is for and what
to do with it. The CATEGORY pick from my real category list (or Classroom -
Live Resources for a lesson package, or None). One clear CALL TO ACTION
(comment, try it, share a win, join Work Hours). For a lesson package, also
a short lesson outline: lesson title, what members learn, and the steps in
order. No price, discount, or sale claim unless a live price was actually
verified - and no buy talk at all when the copy is for inside The Glam
Vault.

THE 7 MODES (a mode is a setting, not a separate farm - it changes the
Pinterest search, the story structure, the shots, and the Skool copy):
1. Announcement / New Drop - a new lesson, resource, or farm is live in
   the Vault. Category: ANNOUNCEMENTS.
2. Prompt Post - a prompt members can copy, run, and share results from.
   Category: PROMPTS.
3. Freebie / Resource Drop - a free resource for members. Category:
   FREEBIES (or a Live Resources lesson package).
4. Lesson / Tutorial - a teach-it step by step Classroom package under
   Live Resources, often with a video.
5. Engagement / Conversation Starter - a question or share thread that
   gets members talking in THE HANGOUT.
6. Encouragement / Celebration - kind words in Words Of Encouragement, or
   a wins thread in Celebrate Your Accomplishments.
7. Product Spotlight - a product or resource shown off for members
   (Ready To Sell Products inside the Vault with no buy talk; selling
   copy with a shop link is for outside the Vault only).

SOLO AGENT FORMS: one per agent, 5 in all. The solo Story Agent form and
the solo Video Agent form must also include the Product Presentation
choice (the full list, None included). The solo Skool Copy Agent form
includes the Skool category choice (my real list, Classroom - Live
Resources, and None). Every solo form produces a clean, ready-to-copy

QUEUE: full runs and solo jobs together, newest first. Each card shows:
character, mode, the Product Presentation choice AND its exact prompt
sentence, topic, length / format, product, Skool category, destination
link, and status (queued / working / done - manual buttons).

RUN IN CHAT: every Queue card gets a Run in Chat button. Pressing it sets
that run to "working" and opens a Run in Chat card showing: the locked
character; Slot 1 and Slot 2 status with thumbnails when uploaded; voice;
mode; Product Presentation choice and its exact prompt sentence; topic;
length / format; product name and link; reference video link when present;
notes; Skool category; and destination link. The card has a COPY PROMPT
button: the copied prompt tells the AI to run THAT exact run with THOSE
exact details, nothing swapped, following the workflow and standing rules
below, and ending by bringing the finished Skool package back in chat for
my approval, never posting it. There is no scheduled pickup. Do not build
one.

THE WORKFLOW (write this into the dashboard and into every run prompt):
1. Pick the outfit on Pinterest (one with an Amazon link when there is a
   product). Copy its picture. Scout member-loved visuals and topics the
   same way, in guest view.
2. Lock the outfit IN CHAT, not in the video tool: using my locked
   character's reference photos, put that character in that exact outfit
   in chat first. Check face match and outfit match.
3. Make the outfit reference sheet IN CHAT: from the approved outfit
   photo, one single 9:16 sheet with front, profile, and three-quarter
   shots of her in that outfit, all on the same photo. Save as PNG.
4. Build the video (when the run has one) with the Consistent Character
   lock: Reference One is her headshot (Slot 1). Reference Two is the
   chat-made outfit reference sheet. NEVER leave Reference Two empty. No
   character bible is needed - the reference photos ARE the lock. Do not
   paste descriptions of her into scene prompts.
5. Create the scenes from that lock, in script order, 9:16.
6. The Skool Copy Agent finishes the package: post title, full post body,
   category pick, one clear call to action, and a lesson outline when the
   run is a lesson package.
7. Return the finished Skool package IN CHAT for my approval. Never post,
   publish, or share it.

THE SCENE PROMPT SHAPE - use this for every scene, and nothing else about her:
"Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it."
The last sentence swaps to match the choice: Holding = "Holding the product, not wearing it." Using = "Using the product on camera, not just holding it." Close-up = "Showing the product close to camera." Beside her = "The product sits beside her in frame - she is not holding it or wearing it." Unboxing = "Unboxing the product on camera." By her face = "Holding the product up beside her face." Mixed scenes = "Holding the product in some scenes and wearing it in others - never both in the same shot." A None run adds no presentation sentence at all.
NEVER describe her in a scene prompt - no face, hair, skin, body, or outfit
description. Describing her overrides the references and creates a
different girl.

PRODUCT PRESENTATION - either/or, never both:
A Wearing run: every prompt ends "wearing the product, not holding it."
A Holding run: every prompt ends "holding the product, not wearing it."
Never show her wearing an outfit while holding that same outfit on a
hanger. Reject and regenerate any image that shows both. If a video needs
both, use separate scenes - holding first, wearing later - never the same
shot. The other choices carry their own sentences (see THE SCENE PROMPT
SHAPE), and a None run ends with no presentation sentence.

STANDING ORDER, baked into every run prompt and the solo Skool Copy form:
"A Skool post is not done until it has a category, one clear call to
action, and - when it points somewhere - a working destination link.
Inside The Glam Vault there is no buy talk."
